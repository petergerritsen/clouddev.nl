stichd

Enterprise Integration platform built with Azure Integration Services

stichd (part of PUMA SE) produces and supplies bodywear, legwear, swimwear, and fanwear for various globally renowned brands such as PUMA, Tommy Hilfiger, Levi’s, Manchester City and Formula 1. With a team from HSO / Motion 10, we have implemented PitWall for stichd, an integration platform on Azure that connects almost all internal and external systems (e.g. SAP, Warehouse management, Product information management, Point of Sales) for messaging and data traffic based on Azure Integration Services.

As an integration consultant/solution architect, I was responsible for the design and implementation (in collaboration with junior/medior developers) of various integration flows.

The following services were mainly used:

  • Azure Service Bus
  • Azure Logic Apps (Standard and Consumption)
  • Azure Functions
  • Azure API Management
  • Azure Event Grid
  • Azure Storage
  • Azure CosmosDB
  • Azure Application Insights
  • Azure Key Vault
  • Bicep and Azure Resource Manager (ARM) templates
  • Azure DevOps Pipelines (YAML)

Saint Gobain Building Distribution Benelux

Migration to Azure, Infrastructure as Code

Saint-Gobain Building Distribution Benelux was a subsidiary of Saint-Gobain, a French multinational which produces a variety of construction, high performance, and other materials. In 2021 the Dutch business units were acquired by BME Group.
In June 2017, Saint-Gobain was hit by a major cyber attack (NotPetya) worldwide. This created the need for Saint-Gobain Building Distribution Benelux to migrate a large part of the internally hosted E-business platform to Microsoft Azure. Additionally, part of the on-premise hosted components (IIS / SQL Server / ETL tooling) needed to be migrated to a new Private Cloud provider.
To minimize the risks of a new cyber attack, many requirements were set from the headquarters for the setup of the Cloud environment. Therefore, it was necessary to regularly communicate with security specialists, architects, and other IT officials from the headquarters in Paris.
In this context, I was mainly involved in:

  • Setting up build/deployment pipelines for deploying all infrastructure components in Azure using Azure Resource Manager templates, Azure CLI, and PowerShell Scripts.
  • Setting up monitoring and alerting based on Application Insights / Azure Monitor.
  • The E-business platform was entirely based on Angular/PHP for the frontend, .NET (core) for the backend APIs, and SQL Server as the database system. A large part of the API endpoints was transformed from a monolith to separate microservices based on .NET Core, often with CosmosDB as the NoSQL datastore.

Setting up new applications for, among other things:

  • Managing the aftersales process (warrantyclaims and complaints)
  • Providing invoice information plus payment options via iDEAL
  • API Gateway as a Strangler Facade for the backend APIs

I regularly presented knowledge-sharing sessions where I guided the internal developers in the setup and management of the components in Azure.
Additionally, I assisted developers in setting up the applications they developed in their scrum teams.
